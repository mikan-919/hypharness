# 0012 止まった課題が出たら全体を止め、利用者の開始の合図と DeLM の過半数の一致で始める

日付: 2026-11-06

## 状況

費用の上限は課題1つあたりだけにかける（ADR 0011）。分解役が課題を作り続けると、1日の費用は課題の数に比例して増える。

## 決定

- 課題が費用の上限を超えたとき、または差し戻しの回数の上限を超えて保留になったとき、ハーネス全体を止める。
- 止まったら、画面に止まった課題と理由（共有文脈の失敗の項目、使った費用）を出す。
- ハーネスは、利用者が開始の合図を出した後、対話の層の論点エージェントの過半数が開始のツールを呼んだときに始まる。分母は、合図の時点で動いている論点エージェントの数とする。
- 論点エージェントが開始のツールを呼べるのは、次をすべて満たすときだけとする。
  - 自分の論点に、未解決の失敗の項目が共有文脈にない。
  - 自分の論点の決定が、ADR として対象のリポジトリに書かれている。
  - 質問の待ち行列に、自分の論点の未回答の質問がない。
- 過半数に届かなければ、呼ばなかった論点エージェントが質問の待ち行列に質問を入れ、対話を続ける。
- 異常で止まった後の再開も、同じ手順で行う。

## 結果

- 1日の総額の上限の代わりに、この停止が費用のブレーキになる。
- 利用者が関わるのは、開始と、異常で止まった後の再開だけになる。

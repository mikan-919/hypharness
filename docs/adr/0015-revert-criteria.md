# 0015 遅れて取れる信号による取り消しの基準

日付: 2026-11-06

## 状況

固定部は、遅れて取れる信号でハーネスの版を取り消す（ADR 0006、0014）。固定部が origin の履歴から読めるのは、統合ブランチの課題ごとのコミットが既定のブランチに届いたか、届いた後に書き直されたか、届かないまま期間が過ぎたか、である。

## 決定

- 判定の単位はハーネスの版とする。その版が作ったコミットのうち、統合ブランチに積まれてから観察の期間（既定は 14 日）内に既定のブランチへ届き、届いた後に変えた行が書き直されていないものを「残った」と数える。期間内に届かなかったコミットは「残らなかった」と数える。
- 新しい版の残った割合が1つ前の版を下回ったら、新しい版を取り消す。比べるのは、どちらの版も一定の件数（既定は 10 件）以上のコミットについて観察の期間が過ぎた後に限る。
- 抜き取った課題での比較（ADR 0006）は、件数が少なくても優先して使う。
- 観察の期間内に、利用者が既定のブランチへ1度もマージしなかった期間は、判定から外す。
- 期間と件数は固定部の設定として持ち、変更は利用者のマージを経て反映する。

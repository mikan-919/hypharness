# 0001 ローカルだけで動かす

日付: 2026-11-06

## 状況

旧実装は、画面と中継を Cloudflare（Workers・Durable Object・R2）に置き、タスクを手元のノードで実行していた。中継はパスキーによるログイン、ノードのペアリング、実行権（期限と世代番号）、暗号化したチェックポイントの保存を持っていた。利用者はこれらに対して、得られるものに見合わないコスト（費用と保守）を払っていた。

## 決定

hypharness をローカルハーネスとして作り直す。1台のマシンで完結させ、Cloudflare 上の画面と中継、ペアリング、実行権、チェックポイントの遠隔保存は作らない。

## 結果

- ノード間の分配と障害からの再開はなくなる。必要になったら、別の ADR で決め直す。
- 旧実装のコードは引き継がない。設計上の知見だけを引き継ぐ。

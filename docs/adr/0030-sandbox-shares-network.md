# 0030 解答役の隔離環境でネットワークを使えるようにする

日付: 2026-11-06

## 状況

ADR 0021 は、解答役のコマンドを動かす隔離環境のネットワークを切り、依存の取得は準備のコマンド（`SETUP_COMMAND`）でホストから行うと決めていた。このため、依存を足す課題（FINAL_GOAL の入力を Monaco にする t12）で、解答役は `bun add` に失敗し、ネットワークの回避策を探してモデルの呼び出しの上限の 60 回を使い切った。

## 決定

- 隔離環境は bubblewrap の `--share-net` でホストとネットワークを共有する。システムを読み取り専用、ホームディレクトリを空、作業ツリーだけを書き込み可にし、環境変数を消す点は変えない。
- 送信先は絞らない。pasta などで外部にだけ出す形は採らない。

## 結果

- 解答役は `bun add` で依存を足し、`package.json` と `bun.lock` の変更をコミットに含められる。
- 解答役は、ホストのローカルのサービスに届く。hypharness の API（127.0.0.1:4173）にも届くため、質問への回答、FINAL_GOAL の書き換え、開始と停止を利用者として行える。この危険は受け入れる。
- 読んだページに埋め込まれた指示でコードを書き換えられる経路ができる。
- 検査のコマンド（`CHECK_COMMAND`）も同じ隔離環境で動くため、ネットワークに出られる。

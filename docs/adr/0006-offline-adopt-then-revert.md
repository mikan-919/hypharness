# 0006 オフラインの変更は、すぐに取れる信号で採用し、遅れて取れる信号で取り消す

日付: 2026-11-06

## 状況

オフラインでは、方針役・分解役・解答役のコードとプロンプトを改良する。採否の信号には、すぐに取れるもの（群の成功率、検証生成役が赤に到達できた割合、引用の確認を通った割合）と、数日から数週間遅れて取れるもの（PR がマージされたか、後で書き直されたか、方針役が決めた名前が残っているか、最終目的の文書が書き直されたか）がある。すぐに取れる信号だけでは、利用者の意図からのずれを止められない。遅れて取れる信号を待つと、改良の1周に数週間かかる。

## 決定

- 新しい版は、すぐに取れる信号で旧版より悪くなければ採用する。すぐに取れる信号はハーネス自身が計算し、改ざんされうるため、採用にだけ使う（ADR 0014）。
- 遅れて取れる信号が悪ければ、元の版に戻す。
- 差し戻しの回数と保留の割合も、すぐに取れる信号に加える（ADR 0010）。分解役は、保留の割合だけをすぐに取れる信号として持つ。

- 抜き取った一部の課題では、旧版と新版のハーネスで独立した DeLM を1回ずつ動かし、同じ課題での成否を比べる。費用が2倍になるのは抜き取った課題だけで、その割合は調整できる。

## 結果

- 抜き取らない課題では、別々の課題での成功率を比べるため、課題の難しさの違いが比較の誤差に入る。抜き取った課題での比較には、この誤差が入らない。

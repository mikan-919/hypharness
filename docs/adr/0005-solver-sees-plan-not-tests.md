# 0005 解答役には方針を渡し、テストは見せない

日付: 2026-11-06

## 状況

検証生成役のテストは、方針に書かれた名前や書式を前提にする。解答役が方針を見ずに別の名前を選ぶと、正しく実装しても報酬が 0 になり、群の成否が名前を当てたかどうかで分かれる。一方、方針を渡すと、方針が課題文から離れたところまで決めていたときに、解答役が要らない分まで作る。

## 決定

- 解答役には課題文と方針を渡す。テストは見せない。
- 方針役は、方針の各項目に課題文からの引用を根拠として付け、根拠のない項目は最小限にし、「やらないこと」を必ず書く。
- 解答役は、受け入れの条件を満たす最小の変更をし、方針と課題文の食い違いは作り足さずに報告する。
- 作りすぎは報酬に反映しない。対策は方針役と解答役のプロンプトで行う。
- DeLM の1回の実行で、報酬が 1 の解答が出た時点で、そのエージェントの解答を PR にし、他のエージェントを止める。

## 結果

- 差分の小ささで解答を選ばないため、テストが確かめない部分で手を抜いた解答を選ぶことを避ける。
- 最初の成功の後に、PR にしない解答へ費用を使わない。

# 0020 検索は常に Fast モードで行う

日付: 2026-11-06

※ 最終目的の本文が版 7 で入れ替わり、この決定は今の目的に含まれない。記録として残す。

## 状況

Parallel の Search API は `mode` で検索の速さと深さを選べる。論点エージェントの対話は、利用者の答えを待つ間に検索を行うため、1回の検索が長くかかると対話全体が遅れる。

## 決定

- `web_search` は `mode: "fast"` を固定で送る。
- モードはツールの引数にしない。論点エージェントはモードを選べない。

## 結果

- 版 7 で目的から外れたため、実装しない。

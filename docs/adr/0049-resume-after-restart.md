# 0049 サーバーを起動し直したら、止まった所から流れを続ける

日付: 2026-11-07

## 状況

論点エージェントの対話は、保存した会話の続きから動き直す。開始の合図の後の流れは、起動し直すと、解いている途中の課題を保留にして「止まった」扱いにしていた。続けるには開始の合図を出し直す必要があり、途中の課題の作業ツリーは消え、分解役は新しい課題を作り直していた。

## 決定

- 起動したときに対話の状態の `started` が真なら、流れを自動で続ける。`finished` があれば自己改良の1周の途中で止まったので、その周を初めからやり直す。
- 解いている途中か、検査に通って統合ブランチに積む前に止まった最後の課題は、作業ツリーを残し、分解役を呼ばずにその課題の続きから進める。統合ブランチへの CAS の元は、作業ツリーの HEAD（積む前なら、その親）にする。
- 解答役の会話は試行ごとに対話の保存に書き、課題を積むか保留にしたら捨てる。続きは、止まった試行を同じ回としてやり直し、前の試行までの会話と「途中で止まった」の知らせから始める。
- 自己改良の弱点を絞る、流れを始めたときの件数（`from`）を対話の状態に保存する。
- 中継の課題ごとの記録と費用は、保存した課題の記録から戻し、課題1つあたりの上限（ADR 0011）を再起動をまたいで数える。
- 作業文脈（ADR 0031）の保存が会話より先を指していたら、別の会話のものとして使わない。

## 結果

- 止まった試行の中の会話は失う。作業ツリーの変更は残る。
- 作業ツリーが残っていない途中の課題は、これまでどおり保留にする。
- 起動し直した直後の呼び出しは、セッション id が変わるため、プロンプトのキャッシュに当たらない。

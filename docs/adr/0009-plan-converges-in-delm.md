# 0009 方針は DeLM の中で1つに収束させる

日付: 2026-11-06

## 状況

DeLM の1回の実行は、エージェントの数だけ完全な解答を返し、それをまとめる仕組みを持たない。検証生成役と解答役に渡す方針は1つでなければならず、方針にはその時点で外部の判定がない。

## 決定

- 方針役の課題を「1つの方針を共有文脈の上で完成させる」と定義する。
- 方針の本文は待ち行列の1項目として1つのエージェントが持ち、更新する。持ち主が止まったら他のエージェントが引き継ぐ。他のエージェントは、案と反論を事実・失敗の項目として書く。
- 方針の各項目が引用の確認を通り、共有文脈に未解決の失敗の項目がないときに提出する。

## 結果

- DeLM の外にまとめ役を置かない。
- 方針の本文を持つエージェントが、方針役の速さを決める。

# 0008 Bun・TypeScript・pi-ai で書く

日付: 2026-11-06

## 決定

- 言語は TypeScript、実行環境は Bun にする。
- モデルの呼び出しは pi-ai（`@earendil-works/pi-ai`）を使う。
- 隔離環境は bubblewrap で作り、systemd でメモリに上限をかける。システムを読み取り専用、作業用ディレクトリだけを書き込み可にし、ネットワークを分け、環境変数を消す。

## 理由

- Web 画面（ADR 0007）と本体を同じ言語で書ける。
- 処理時間の大半はモデルの応答待ちとテストの実行で、言語の実行速度は全体に効かない。
- 旧実装で、pi-ai が DeepInfra と OpenAI のサインインの両方に使えることを確かめている。旧実装のコードは引き継がない。

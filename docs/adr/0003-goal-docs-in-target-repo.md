# 0003 最終目的を対象のリポジトリの文書として残し、ハーネスが課題文に分ける

日付: 2026-11-06

## 状況

旧実装は、最終目的を `goals/<名前>.md` の1ファイルに書き、そこから評価のためだけの課題を生成していた。ファイルは何をするかの一覧で、なぜそう決めたかを残していなかった。

## 決定

- 利用者は、ハーネスとの対話で最終目的を鋭くしていく。対話もハーネス自身（DeLM）で動かす。
- 最終目的は、対象のリポジトリの中に、本文・ADR・用語集の一式として残す。
- 分解役が最終目的を課題文に分ける。課題文は実際にやる仕事であり、評価のためだけの課題は作らない。

## 結果

- 最終目的の文書の書き換えが `git log` に残り、分解役の改良の信号として機械的に追える。
- 分解役が根拠にするのは、この文書一式と対象のリポジトリのコードに限られる。

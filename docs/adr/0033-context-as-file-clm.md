# 0033 文脈をファイルとして扱う（Context Language Models）

日付: 2026-11-06

状態: 一部を ADR 0031 で置き換えた。edit_context は会話全体を作業文脈に置き換える形にし、モデルに渡す会話を作り直すのは編集としきい値のときだけにした。

## 状況

ハーネスのエージェントは、会話を追記だけのメッセージ列として持つ。長い対話や長い課題では文脈が伸び続け、費用が増え、関係の無い情報で推論が乱れる。論点エージェントの会話は `~/.hyph/dialogs/` に保存しているが、モデル自身が文脈を縮める手段は無い。

Context Language Models（arXiv:2609.37725、実装 `facebookresearch/context-language-models` の `clm_harness`）は、会話をファイルに写し、モデルが普通の編集でそのファイルを書き換え、書き換えたファイルを次の文脈にする。システムプロンプトと課題文はファイルの外に固定する。既存のモデルに zero-shot で使える。

## 決定

- エージェントごとに文脈ファイル `~/.hyph/ctx/<エージェントの id>.md` を持ち、会話をそこに写す。ファイルのパスをシステムプロンプトに書く。
- モデルは `edit_context` ツール（引数 `old`・`new`）で文脈を書き換える。`old` が1回だけ現れるときにその1箇所を置き換える。0回・2回以上のときは変えず、理由を返す。
- 毎回のモデル呼び出しの前に、文脈ファイルの中身をメッセージ列に戻す。システムプロンプトと最初の課題文はファイルの外に置く。
- 文脈ファイルを空にする編集は受け付けない。
- 文脈ファイルのトークン数がモデルの `contextWindow` の 70% を超えたら、`edit_context` の結果に要約を求める指示を添える。
- 文脈ファイルは保存し、再起動の後に続きから始める。
- suffix cache の再利用はしない。推論エンジンを替える必要がある。

## 結果

- モデルが自分で文脈の大きさを決められる。ハーネスは上限に近づいたことを伝えるだけになる。
- `edit_context` の失敗（`old` が見つからない、2回以上ある）は、モデルが書き直す負担になる。
- 文脈ファイルと `~/.hyph/dialogs/` の保存の両方を持つため、再起動時の整合を取る処理が要る。

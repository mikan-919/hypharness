# 0010 流れが止まったら1つ前の役に差し戻し、上限を超えたら分解役に戻す

日付: 2026-11-06

## 状況

課題1つ分の流れ（分解役→方針役→検証生成役→解答役）は、次の場合に止まる。

- 検証生成役が、上限の回数までに正しい理由で失敗するテストを書けない。
- 解答役の DeLM で、報酬が 1 の解答が出ない。
- 解答役が、方針と課題文の食い違いを報告する。

## 決定

- テストが書けない場合と食い違いの報告は方針役に、解答が出ない場合は検証生成役か方針役に差し戻す。差し戻しには、止まった理由として共有文脈の失敗の項目を添える。
- 差し戻しの回数が上限を超えたら、課題を保留にし、分解役が次に課題を作るときの材料にする。
- 利用者には聞かない。

## 結果

- 差し戻しの回数と保留の割合を、オフラインのすぐに取れる信号に加える（ADR 0006）。分解役は保留の割合を、最初のすぐに取れる信号として持つ。

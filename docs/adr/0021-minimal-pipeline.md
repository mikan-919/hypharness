# 0021 開始の合図から統合ブランチまでの最小の流れ

日付: 2026-11-06

## 状況

最終目的を詰める対話（ADR 0016、0018）ができた。開始の合図の後に、分解役・解答役・統合ブランチ（ADR 0003、0013）をつなぐ。ハーネス自身が自分を改良していけるように（ADR 0014）、最初は最小の形で通す。

## 決定

- 開始の合図のボタンは、論点エージェントの過半数が開始可のときだけ押せる。サーバーも同じ条件で確かめ、満たさなければ断る（ADR 0012 の過半数を、合図を出せる条件にする）。
- 開始の合図の後、次を繰り返す。
  1. 統合ブランチ `hypharness/integration` の先端から、課題ごとの作業ツリー（git worktree）を `~/.hyph/worktrees/` に作る。
  2. 分解役が `FINAL_GOAL.md`・ADR・コードを読み、次の課題文を1つ作る。最終目的を満たしたと判断したら終える。
  3. 準備のコマンド（`SETUP_COMMAND`）を作業ツリーでホストから動かす。依存の取得など、ネットワークが要る処理はここで行う。
  4. 解答役が課題を解く。コマンドは bubblewrap の隔離環境で動かす。隔離環境は、システムを読み取り専用、ホームディレクトリを空、作業ツリーだけを書き込み可にし、ネットワークを切り、環境変数を消す。
  5. 検査のコマンド（`CHECK_COMMAND`）を隔離環境で動かす。通れば報酬 1 とし、課題ごとに1コミットとして統合ブランチに積む。origin があれば統合ブランチを push する。
  6. 検査に落ちたら、出力を添えて解答役に差し戻す（ADR 0010）。3回落ちたら課題を保留にし、流れ全体を止める（ADR 0012）。
- エージェントの動き（呼んだツール、その結果の要約、書いている途中の文）を、時系列で画面に出す。

## 結果

- 方針役・検証生成役・DeLM はまだ入れない。報酬は既存の検査だけで決める。
- 解答役のツールは隔離環境で動くが、エージェントの処理そのものはホストで動く。ハーネスの中身を隔離環境に入れる形（ADR 0014）は後で入れる。
- 準備と検査のコマンドは、対象のリポジトリごとに環境変数で渡す。`CHECK_COMMAND` がなければ、差分があることだけを確かめる。

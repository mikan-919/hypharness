# 0018 最終目的の本文を利用者と論点エージェントが一緒に書き換える

日付: 2026-11-06

## 状況

対話の画面（ADR 0016）は、論点エージェントが1問ずつ聞き、利用者が答える形だった。最終目的の本文は、答えを受けて論点エージェントが書くもので、利用者が直接書き換える場所がなかった。

## 決定

- 対象のリポジトリの `FINAL_GOAL.md` を最終目的の本文とし、画面の中央に置く。利用者はその場で書き換えられる。
- 論点エージェントも本文を直接書き換える。承認は待たない。
- 書き換えはすべて、誰が・なぜ・どこを変えたかを差分付きで履歴に残す。利用者は履歴から、ある書き換えの前の版に戻せる。
- 本文は版の番号を持つ。書き換えには読んだ版の番号を付け、その後に別の書き換えが入っていたら断る。断られた側は最新の版を読み直してから書き直す。利用者の書き換えはエージェントに上書きされない。
- 論点エージェントは、利用者の書き換えを差分で受け取る。
- 利用者への質問は、論点エージェントが自分では決められない点に限る。ADR と用語集は、これまでどおり論点エージェントが書く。

## 結果

- 対話の中心が、質問と答えから本文の書き換えに移る。
- 承認の手順を持たないため、利用者はエージェントの書き換えを後から履歴で確かめて戻す。

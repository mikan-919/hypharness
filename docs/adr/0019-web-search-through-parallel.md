# 0019 web_search を Parallel の Search API で実装する

日付: 2026-11-06

※ 最終目的の本文が版 7 で入れ替わり、この決定は今の目的に含まれない。記録として残す。

## 状況

論点エージェントのツールは `ask`・`record`・`list_files`・`read_file`・`read_goal`・`edit_goal`・`write_doc`・`ready` で、リポジトリの中しか読めない。外部の文献や API の仕様を根拠にする必要が出たとき、調べる手段が無い。

## 決定

- 論点エージェントに `web_search` ツールを渡す。検索は Parallel の Search API（`POST https://api.parallel.ai/v1beta/search`）を fetch で直接呼ぶ。SDK は足さない。
- 引数は `objective`（必須）と `max_results`（既定 5、1〜20）。戻り値は結果ごとの `title`・`url`・`excerpts` を並べたテキストで、全体を 8,000 文字で切る。
- `PARALLEL_API_KEY` があるときだけ `TOOLS` に加える。無いときはツールの一覧を変えない。
- 失敗（HTTP エラー、タイムアウト 30 秒、応答の形の違い）は isError のツール結果にして対話を続ける。
- 検索1回の費用を $0.005 とし、その検索を行った課題の費用に足す。中継にモデル以外の費用を受け取る口を足し、モデルの利用料と同じ上限で数える。失敗した検索の費用は数えない。
- 検索結果のページ本文の取得（extract）と、検索結果のモデルによる要約はしない。

## 結果

- 版 7 で目的から外れたため、実装しない。中継にモデル以外の費用を受け取る口を足す決定も、この ADR とともに使わない。

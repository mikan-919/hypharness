# 0032 対話画面の右列をタブに分ける

日付: 2026-11-06

## 状況

`routes/style.ts` の `.shell` は 240px・1fr・300px の3列を 100vh に置き、`routes/page.tsx` の右列にはメトリクス・書き換えの履歴・共有文脈が縦に並ぶ。中央列には高さ 55vh の FINAL_GOAL の入力欄と質問が縦に並ぶ。3列がそれぞれ独立にスクロールするため、どの欄も狭く、内容を見るたびにスクロールが要る。

## 決定

- 右列を「共有文脈」「書き換えの履歴」「費用」の3つのタブに分ける。同時に見せるのは1つで、既定は「共有文脈」。スクロールするのはタブの中だけにする。
- 中央列の FINAL_GOAL の入力欄は高さ 40vh に固定し、内容が長いときは欄の中でスクロールする。見出し（FINAL_GOAL.md と版）は欄の上に残す。
- 質問は入力欄の下に置く。質問が無いときは「質問はありません」と出す。
- 左列の論点一覧は変えない。
- 幅 900px 以下では今のとおり1列にし、ページ全体をスクロールさせる。

## 結果

- 画面を開いたときに同時に見えるのは、論点の一覧、FINAL_GOAL、選んだタブの1つになる。
- 共有文脈と書き換えの履歴を同時に見ることはできない。タブを切り替える操作が増える。
- タブの状態は保存しない。再読み込みすると「共有文脈」に戻る。
